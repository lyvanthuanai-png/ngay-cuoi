# Ngày cuối

Game thử chạy trên trình duyệt: nhập hồ sơ của bạn, sống một ngày đi làm, gặp rủi ro thật của nghề, đi tiếp theo tôn giáo của mình, rồi học cách phòng tránh.

Chuyện hư cấu. Khả năng xảy ra trong bản thử là giả định, chưa dựa trên số liệu thật. Nội dung sức khỏe chỉ để tham khảo, chưa được bác sĩ duyệt. Cấp cứu: gọi 115.
